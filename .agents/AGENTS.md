
## Git Workflow
- **NEVER** run `git add`, `git commit`, or `git push` automatically on behalf of the user.
- The user prefers to run these commands manually.
- When work is complete, provide the full git commit command with a 6-7 word message (without writing 'feat:' or 'fix:' in front), for example: `git commit -m "Your short commit message here"`. Then instruct the user to commit and push the changes themselves.
